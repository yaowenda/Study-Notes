DiffusionFace provides 570,000 synthetic faces (plus 30,000 real ones for comparison) using 11 diffusion models, with high-resolution images and rich metadata for advanced analysis.
DiffusionFace 使用 11 种扩散模型生成 57 万张合成人脸（另有 3 万张真实人脸用于对比），并提供高分辨率图像和丰富的元数据，以进行高级分析 

AGFD-20K offers 20,000 realistic, high-resolution faces generated via Stable Diffusion, balanced across demographics for training purposes.
AGFD-20K 提供 20,000 张通过稳定扩散生成的逼真高分辨率人脸，这些面孔在不同人群中分布均衡，以用于训练目的 

SFHQ (Synthetic Faces High Quality) includes about 425,000 curated 1024x1024 images, generated with Stable Diffusion to achieve lifelike results without artifacts.
SFHQ（高质量合成人脸库）包含约 425,000 张精选的 1024x1024 像素图像，这些图像采用稳定扩散技术生成，以实现逼真且无伪影的效果 

AI-Face is a million-scale dataset with demographically annotated faces, including those from diffusion models, aimed at fairness benchmarks in recognition systems.
AI-Face 是一个包含百万张人脸的数据集，其中包含经过人口统计标注的人脸，包括来自扩散模型的人脸，旨在为识别系统的公平性设定基准 

DCFace uses a dual-condition diffusion model to generate synthetic faces, focusing on high-quality outputs for applications like privacy protection.
DCFace 使用双条件扩散模型生成合成人脸，专注于为隐私保护等应用提供高质量的输出结果
